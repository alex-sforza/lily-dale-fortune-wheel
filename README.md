# Lily-Dale Fortune Wheel

Интерактивное «Колесо Фортуны» для ивента «Ярмарка Шёпотов» на Lily-Dale.

## Файлы

- `index.html` — страница колеса.
- `style.css` — оформление.
- `script.js` — 100 секторов, случайные результаты, анимация и локальный лимит.

## Публикация через GitHub Pages

В репозитории откройте **Settings → Pages → Build and deployment → Deploy from a branch**, затем выберите `main` и `/ (root)`.

Страница будет доступна по адресу:

`https://alex-sforza.github.io/lily-dale-fortune-wheel/`

## Встраивание на форум

```html
<iframe
  src="https://alex-sforza.github.io/lily-dale-fortune-wheel/"
```

## Ограничение вращений

Текущий лимит 3 вращения в неделю хранится в `localStorage`. Это интерфейсное ограничение, а не защищённый серверный лимит: очистка данных браузера или другое устройство позволит начать счётчик заново.

Для строгого контроля со стороны АМС позже можно добавить небольшой backend/API.

## Изменение призов

Все результаты находятся в массиве `prizes` в `script.js`. Сейчас используется 100 равновероятных визуальных секторов. Баланс меняется через содержимое и количество записей в массиве.
